# LineCurativos — Android Offline

Versão Android offline do LineCurativos. O aplicativo usa somente arquivos locais (HTML/CSS/JavaScript) dentro do APK e não precisa de Django, servidor ou internet para executar a triagem.

Abra a pasta no Android Studio, sincronize o Gradle e use Run para testar ou Build > Build APK(s) para gerar o APK.
